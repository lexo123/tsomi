# ცომი — საცხობის პორტფოლიო

გამოგონილი საცხობის ქართული, მობილურზე მორგებული პორტფოლიოს საიტი. ეს ვერსია შექმნილია GitHub Pages-ისთვის და არ იღებს ნამდვილ შეკვეთებს ან გადახდებს.

შენარჩუნებულია 22 პროდუქტის კატალოგი 36 ფასიანი ვარიანტით, კატეგორიები, სამარხვო ფილტრი, პროდუქტის დეტალები, 22 გენერირებული პროდუქტის ფოტო, 5 ფოტოს გალერეა, რუკა და საკონტაქტო ბმულები. დაჯავშნის ფორმა მხოლოდ ბრაუზერში აჩვენებს დემონსტრაციის შედეგს — ინფორმაცია არ იგზავნება სერვერზე და არ ინახება.

## გაშვება

საჭიროა Node.js 22.13 ან ახალი ვერსია.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## GitHub Pages

ატვირთეთ ეს საქაღალდე ცალკე GitHub საცავში `main` ტოტზე. საცავის Settings → Pages → Build and deployment → Source-ში აირჩიეთ GitHub Actions. `.github/workflows/deploy.yml` ავტომატურად ააწყობს და გამოაქვეყნებს საიტს. განახლებები ქვეყნდება ყოველი ახალი push-ისას.

ფოტოებისა და სკრიპტების მისამართები იყენებს განთავსების საბაზო ბილიკს. workflow საბაზო ბილიკს GitHub Pages-ის პარამეტრებიდან იღებს, ამიტომ საცავის სახელი წინასწარ ჩაწერილი არ არის. ლოკალური შემოწმებისთვის:

```sh
PAGES_BASE_PATH=/tsomi-bakery/ npm run build
npm run preview
```

ეს ვერსია არ შეიცავს Cloudflare-ის სერვერს, D1 ბაზას, Sites-ის იდენტიფიკატორებს ან ანგარიშზე წვდომის მონაცემებს.

- ფოტოები: `public/images/products/`; ფაილების სახელები: `lib/product-images.ts`.
- გალერეა: `lib/gallery.ts`.
